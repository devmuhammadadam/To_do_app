# To-Do App ✅

A simple daily task management application built with HTML, CSS, and JavaScript.

## Overview

To-Do App is a task management application that helps users organize and keep track of their daily tasks.

Users can add new tasks, mark completed tasks, and delete tasks they no longer need. The application uses the browser's `localStorage` to save tasks, allowing them to remain available even after closing and reopening the browser.

## Features

- **Add Tasks:** Create new tasks and add them to your daily task list.
- **Complete Tasks:** Mark tasks as completed when finished.
- **Delete Tasks:** Remove tasks from the list whenever needed.
- **Persistent Storage:** Save tasks using browser `localStorage`.
- **Daily Task Management:** Keep your tasks organized in one place.
